# 🛒 E-Commerce Cohort Retention & CLV Analysis

## 📌 Project Overview
This project analyzes 100,000+ transaction records from a Brazilian e-commerce dataset (Olist) to measure customer loyalty, retention decay, and Lifetime Value (CLV) over a 12-month period.

## 🛠️ Tools & Technologies
* **Python (Pandas):** Data cleaning, normalization, and cohort indexing.
* **SQL:** Engineered a 5-table Star Schema backend.
* **Power BI:** Matrix heatmap visualization and executive dashboarding.

## 📊 Key Business Insights
* **Retention Decay:** Identified a 99%+ "one-and-done" buyer drop-off rate after the initial purchase month.
* **Power Users:** Isolated the top 1% of high-value customers, establishing a $1,095.80 spending threshold.
* **Customer Lifetime Value:** Calculated average CLV to guide future customer acquisition cost (CAC) strategies.
